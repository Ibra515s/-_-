# نظام إدارة حملة صلاة الفجر

تطبيق ويب مستقل: Node.js + Express + **MongoDB**، واجهات عربية RTL بلا خطوة بناء. بدون Docker.

## التشغيل محليًا
1. ثبّت Node 20+ وشغّل MongoDB محليًا (أو أنشئ عنقودًا مجانيًا على MongoDB Atlas وخذ رابط الاتصال).
2. ```bash
   npm install
   MONGODB_URI='mongodb://127.0.0.1:27017' ADMIN_PASSWORD='كلمة-مرور-قوية' npm start     # المنفذ 3000
   ```
- إن لم تضبط `ADMIN_PASSWORD` تُولَّد كلمة مؤقتة وتُطبع في الطرفية مرة واحدة.
- دخول المشرف: `/#/staff-login` — اسم المستخدم `admin` (أو `ADMIN_USERNAME`).
- **HTTPS إلزامي** في الإنتاج وإلا لن تعمل الكاميرا (منصات الاستضافة تعطيك HTTPS تلقائيًا). اضبط `TRUST_PROXY=1` خلف وسيط.

## متغيرات البيئة
| المتغير | الافتراضي | الوصف |
|---|---|---|
| MONGODB_URI | mongodb://127.0.0.1:27017 | رابط الاتصال (مع Atlas: `mongodb+srv://...`) |
| MONGODB_DB | fajr | اسم قاعدة البيانات |
| PORT | 3000 | المنفذ |
| ADMIN_USERNAME / ADMIN_PASSWORD | admin / مولّدة | إنشاء المشرف الرئيسي عند أول تشغيل |
| TRUST_PROXY | — | 1 خلف وسيط عكسي (لازم لتحديد معدل الدخول وكوكي Secure) |
| APP_TIMEZONE | Asia/Riyadh | المنطقة الزمنية الافتراضية |

## الاستضافة المجانية (بدون Docker)
- **قاعدة البيانات:** MongoDB Atlas مجاني (M0) — البيانات محفوظة دائمًا حتى لو نام الخادم أو أُعيد تشغيله. في Atlas: أنشئ مستخدمًا، وفي Network Access أضف `0.0.0.0/0` (الاستضافات المجانية لا تملك IP ثابتًا).
- **التطبيق:** أي منصة تشغّل Node مباشرة (Render / Railway / Koyeb ...): الأمر `npm install` للبناء و`npm start` للتشغيل، وأضف المتغيرات أعلاه. لا تحتاج قرصًا دائمًا لأن كل شيء (بما فيه الشعار) داخل MongoDB.
- الخطط المجانية قد "تنام" عند عدم الاستخدام فيتأخر أول طلب عدة ثوانٍ؛ هذا لا يفقد بيانات.

## الإعداد الأول (من لوحة المشرف)
1. الإعدادات: اسم المسجد، الشعار، **تاريخ بداية الحملة**، المنطقة الزمنية.
2. لوحة الصدارة: أنشئ لوحة (المدة + نقاط الحضور + الظهور).
3. المشاركون ← إنشاء حسابات جديدة (مثلًا 500) ← تصدير البطاقات PDF.
4. المساعدون: أنشئ حسابات لمن سيمسحون من هواتفهم.

## الطباعة
PDF بمقاس A4، ست بطاقات/صفحة (CR80 ‏85.6×54 ملم) مع علامات قص. اطبع بنسبة **100%**؛ في أسفل الصفحة مسطرة 100 ملم للتحقق.

## الاختبارات
يتطلب MongoDB يعمل. تُنشأ قاعدة مؤقتة باسم عشوائي وتُحذف بعد الانتهاء:
```bash
MONGODB_URI='mongodb://127.0.0.1:27017' npm test
```

## النسخ الاحتياطي
Atlas المجاني لا يوفّر نسخًا احتياطية مجدولة؛ شغّل دوريًا `mongodump --uri "$MONGODB_URI" --db fajr` واحتفظ بالمخرجات خارج الاستضافة.

## ملاحظات تصميمية
- QR يحوي المعرف فقط؛ هو معرّف حساب لا إثبات هوية (يمكن تصويره). يعتمد المشرفون على الاسم المكتوب على البطاقة عند الحاجة.
- منع التكرار بقيد فريد في قاعدة البيانات (مشارك+يوم) وقيد فريد لقيود النقاط.
- استبدال المعرف يُبقي الهوية الداخلية والحضور والنقاط؛ المعرف القديم يُرفض برسالة «بطاقة مستبدلة».
- لوحة الصدارة تعرض الاسم الأول والأخير افتراضيًا (قابل للتغيير) ولا تعرض هاتفًا أو عمرًا أو معرفًا.
- المسح يتطلب اتصالًا بالإنترنت (لا توجد قائمة انتظار دون اتصال).
